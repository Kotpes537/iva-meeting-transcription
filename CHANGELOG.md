# История изменений

## 0.3.2 — 2026-09-23

- Telegram-сообщение теперь начинается просто с «Итоги встречи» без даты, времени и технических метаданных.
- Тайминги удалены из тезисов Telegram; они остаются в Word и полном транскрипте.
- В Telegram добавлен отдельный блок задач с ответственными и сроками из Word.

## 0.3.1 — 2026-09-23

- Усилен контроль состава участников: люди, которых только упомянули, не перечисляются как присутствовавшие.
- Если модель перечислила решения или открытые вопросы, но пропустила обсуждённые проблемы, плагин повторно запрашивает полный JSON с этим разделом вместо вывода нуля.

## 0.3.0 — 2026-09-23

- Системные инструкции для итогов приведены к запросу владельца: участники, повестка, вопросы и проблемы, статистика решений, задачи с ответственными и сроками. Word сохраняет полный автоматический транскрипт в каждом режиме.
- Добавлены распространённые аудиоформаты WAV, FLAC, Ogg, Opus, AAC, WebM и аудио MP4. Перед передачей провайдеру `ffprobe` проверяет наличие аудиопотока и отсутствие видеодорожки.
- Дата и время из имени файла проходят проверку календаря; при отсутствии валидной даты используется дата записи из метаданных, если она корректна.
- Патч Iva для входящих файлов больше 20 МБ расширен на эти аудиоформаты.

## 0.2.4 — 2026-09-23

- Патч для Iva 0.4.7 теперь передаёт в плагин большие M4A/MP3, присланные Telegram как `audio` или `document`.
- Если у Telegram audio нет имени файла, расширение определяется по поддерживаемому MIME-типу.
- Добавлены проверки обоих вариантов; входящий файл больше 20 МБ ещё требует повторного сквозного теста.

## 0.2.3 — 2026-09-23

- Исправлена несовместимость объявления типов с установленной Iva 0.4.7: ошибка worker теперь приводится к `Error` перед обработкой.

## 0.2.2 — 2026-09-23

- Word с полным транскриптом отправляется даже при сбое генерации саммари; при последующем успехе отправляется окончательный документ с выбранными итогами.
- Отправка Word происходит до сообщения с тезисами. Если Telegram не принимает ответ на исходное сообщение, документ повторно отправляется в чат без привязки.
- Уточнено, что локальные автотесты не оставляют Word после завершения.

## 0.2.1 — 2026-09-23

- Word теперь всегда содержит полный транскрипт с таймингами и метками спикеров.
- Режимы уточнены: `bullets` включает короткие итоги и транскрипт, `transcript` — только транскрипт, `both` — подробные итоги и транскрипт.
- Перед распознаванием аудио плагин пытается перепаковать файл без перекодирования аудиопотока, метаданных и обложки; исходник остаётся сохранённым.

## 0.2.0 — 2026-09-23

- Саммари и тезисы теперь составляет модель, выбранная в Iva через `MODEL_PROVIDER`. Зависимость от Gemini и `GEMINI_API_KEY` удалена.
- Лимит ожидания ответа модели для саммари увеличен до 10 минут; обработка долгой задачи удерживается расписанием Iva через `waitUntil`.
- Саммари запускается с `THINKING_EFFORT=low` в отдельном worker по умолчанию; уровень можно выбрать отдельно, не меняя чат Iva.

## 0.1.0 — 2026-09-23

- Первый пакет Agent Plugin для Iva 0.4.7: M4A/MP3, очередь, распознавание, итоги в Telegram и три варианта Word.
- Совместимый патч для передачи больших аудиофайлов из Iva в плагин через локальный Telegram Bot API.
